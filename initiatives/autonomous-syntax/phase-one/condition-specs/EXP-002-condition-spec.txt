--------------------------------------------------------------------------------
RESEARCH QUESTION
--------------------------------------------------------------------------------

When given the necessity of constructing a formal system for expressing
temporal relationships without recourse to any existing natural language's
approach to tense or aspect, what structural choices does a nonhuman agent
make? How do these choices compare to EXP-001's causality system — does the
same model reach for similar structural logic across different semantic domains,
suggesting domain-general formal preference?

--------------------------------------------------------------------------------
PROMPT (EXACT — DO NOT PARAPHRASE)
--------------------------------------------------------------------------------

You are being asked to construct a formal system for expressing time and
temporal relationships. This system must be capable of representing: past,
present, future, duration, and simultaneity.

Constraints:
- You may not borrow from any natural language's approach to tense or aspect
- You may not use existing notation from physics, mathematics, or logic
- You must build from first principles
- There is no correct answer
- Document every structural decision and the reasoning behind it

Produce the complete system. Then produce five example expressions using it
with full explanations.

--------------------------------------------------------------------------------
ANALYST NOTES (PRE-OUTPUT)
--------------------------------------------------------------------------------

This is the second Phase One experiment, designed to run in parallel with
EXP-001 for cross-domain comparison. Temporal expression is among the most
variable features across natural languages — tense, aspect, and evidentiality
are encoded in radically different ways across human languages. This makes
it a strong test domain: a model with genuine formal preferences should
reveal them here, while a model that is simply disguising natural language
patterns may default to English-style tense structures despite the constraint.

Key questions: Does the model produce a linear timeline model, a relational
model, or something outside those categories? How does it handle the
simultaneity constraint — a feature that many natural languages encode
differently? Does the structural logic of this system resemble EXP-001's
causality system in any meaningful way?
